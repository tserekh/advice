# SochiGPT - RAG Bot для слабых серверов

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install pandas pyTelegramBotAPI numpy
```

### 2. Создание тестовых данных

```bash
python create_test_data.py
```

### 3. Подготовка RAG индекса

```bash
python prepare_simple.py
```

### 4. Запуск бота

```bash
# Создайте файл credentials/sochi.txt с токеном вашего Telegram бота
mkdir -p credentials
echo "YOUR_BOT_TOKEN" > credentials/sochi.txt

# Запустите бота
python app_simple.py
```

## 📊 Требования к ресурсам

Эта версия оптимизирована для **очень слабых серверов**:

- **ОЗУ**: ~50 MB
- **Диск**: ~100 MB  
- **CPU**: Любое (работает без GPU)
- **Сеть**: Не требуется после установки

### Как это работает?

Вместо тяжелых ML моделей используется:
- **TF-IDF векторизация** для создания эмбеддингов
- **Косинусное сходство** для поиска похожих вопросов
- **Pickle кэш** для хранения индекса на диске

Это позволяет работать на серверах с:
- Менее 1 ГБ ОЗУ
- Менее 500 MB свободного места на диске
- Без доступа к интернету (после настройки)

## 📝 Добавление своих данных

1. Отредактируйте `create_test_data.py` и добавьте свои вопросы-ответы
2. Запустите `python create_test_data.py`
3. Переиндексируйте: `python prepare_simple.py`

Или создайте CSV файл в формате:

```csv
question_message,reply_message
Ваш вопрос,Ваш ответ
Еще вопрос,Еще ответ
```

## 🔧 Конфигурация

Основные настройки в `config.py`:

- `vector_db_path` - где хранить индекс
- `token_path` - файл с токеном Telegram бота
- `top_k_retrieval` - сколько результатов искать (по умолчанию 3)

## ⚡ Производительность

На тестовых данных (10 Q&A пар):
- Время подготовки: < 1 секунды
- Время ответа: < 100 ms
- Размер индекса: ~8 KB

При 1000 вопросах:
- Размер индекса: ~500 KB
- Время ответа: < 500 ms

## 🆙 Апгрейд до полной версии

Когда появятся ресурсы, можно перейти на ML эмбеддинги:

```bash
# Установите sentence-transformers
pip install sentence-transformers chromadb

# Используйте полную версию
python prepare.py
python app.py
```

Это улучшит качество поиска, но потребует:
- ~500 MB диска
- ~1 GB ОЗУ
- Интернет для загрузки модели
